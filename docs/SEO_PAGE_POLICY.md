# SEO Page Quality Policy

ToolScout must not publish a page merely because an intent has search demand.

A candidate must have:

- a distinct user problem;
- at least two genuinely relevant tools or a useful comparison;
- original recommendation logic;
- transparent pricing/feature context where available;
- a clear reason the page is useful beyond merchant copy;
- no copied merchant descriptions as the primary content;
- no doorway-page variants created only by swapping keywords.

## Publishing states

`candidate` → discovered automatically

`review` → quality checks passed and awaiting approval

`published` → explicitly approved

`rejected` → insufficient value or duplication

Automation may discover and score candidates, but it must not silently publish new SEO pages.

This protects the project from scaled-content and thin-affiliate patterns while still allowing the site to scale when it has genuine utility.
