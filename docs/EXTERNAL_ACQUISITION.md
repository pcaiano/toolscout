## Channel rules
- LinkedIn: problem-led, useful post, one relevant link.
- Reddit/community: answer the question first; link only when useful and allowed.
- X: concise problem + insight + resource.
- Newsletter: one practical shortlist per send.
- SEO: intent page plus supporting guide and internal links.

## Tracking
Use UTMs on distributed links:
- LinkedIn: `utm_source=linkedin&utm_medium=social&utm_campaign=<campaign>`
- Reddit: `utm_source=reddit&utm_medium=community&utm_campaign=<campaign>`
- X: `utm_source=x&utm_medium=social&utm_campaign=<campaign>`
- Newsletter: `utm_source=newsletter&utm_medium=email&utm_campaign=<campaign>`

## First-100 milestone
- 100 external sessions
- 25 external searches
- 40 external outbound clicks
- 10 monetized clicks
- first verified affiliate commission

## Decision rules
- Sessions without clicks -> improve page/recommendation/CTA.
- Clicks without affiliate coverage -> prioritize affiliate application.
- Search impressions with weak CTR -> improve title/meta and intent match.
- No meaningful acquisition after sufficient distribution -> deprioritize the topic.

## Guardrails
- Never count owner testing as acquisition proof.
- Never treat estimated revenue as actual revenue.
- Never mass-post links to communities where they are not contextually useful.
- Keep affiliate disclosures visible where required.
