# ToolScout — First Revenue Sprint

## Goal

Generate the first tracked affiliate revenue as quickly as possible with €0 investment.

## Priority #1 — systeme.io

Reason:
- official affiliate program publishes 60% lifetime recurring commissions;
- program is free to join;
- systeme.io states anyone can participate and does not require being a customer;
- this removes the affiliate-approval bottleneck that exists for several other SaaS programs.

Required user action: create the free affiliate account and obtain the unique affiliate URL. Do not invent or infer the URL.

## Priority #2 — Jotform

Reason:
- official affiliate program publishes 30% recurring commission;
- Jotform states applications are reviewed within one business day.

Use after the systeme.io path is live or in parallel only if the user can complete the application without meaningful time cost.

## Priority #3 — HubSpot / Pipedrive

Use for recurring-revenue diversification after the first monetizable path is working.

## Priority #4 — Semrush

Use for high-value one-off commission opportunities. It is attractive for first-revenue economics but does not by itself create the same lifetime recurring stream as systeme.io.

## Build rule

Do not build more backend or SEO infrastructure before the first affiliate link is active and the first monetization page can send a real tracked visitor.

## Success sequence

1. Affiliate account created.
2. Real affiliate URL obtained.
3. URL inserted into ToolScout configuration.
4. `/go/systeme-io` verified.
5. Monetization page published.
6. First visitor reaches the page.
7. First affiliate click recorded.
8. First commission recorded.
9. Only then expand catalogue/SEO automation.
