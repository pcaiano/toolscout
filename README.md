# ToolScout

**Find the right AI & software tool for the job.**

ToolScout is a lightweight recommendation engine designed to help people choose software and AI tools based on their actual needs — not generic rankings.

## MVP

- Interactive recommendation flow
- Curated tool database
- Deterministic scoring engine
- Affiliate-ready outbound links
- SEO-friendly tool pages
- No paid infrastructure required for the initial MVP

## Principles

- Recommendations should be useful before they are monetized.
- Pricing/features must be traceable to a source and verification date.
- Never invent product capabilities, pricing, reviews, or affiliate relationships.
- Affiliate relationships will be disclosed clearly.
- Start small, measure demand, then automate.
