GitHub Actions conservation mode ended on 2026-10-01.
Original pre-conservation workflows remain preserved on branch pre-conservation-2026-09-13.

ToolScout 2.0 does not restore the old scheduled workflow topology. Cloudflare Workers own scheduled production execution and Render is an execution sidecar. GitHub Actions are limited to CI, explicit recovery, telemetry refreshes, and bounded manual fallbacks so they cannot become a second scheduler or deployment authority.

Frozen conservation stubs remain temporarily for auditability and will be removed or selectively replaced after compatibility review.
